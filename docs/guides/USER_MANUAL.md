## 🏁 はじめに

QuestEdは探究型学習を支援する総合プラットフォームです。本マニュアルでは、各役割に応じた機能の使い方を詳しく説明します。

### システムの構成

- **管理者**: 学校・年度・ユーザー管理
- **教師**: カリキュラム作成・生徒指導・評価
- **生徒**: 探究学習・活動記録・目標管理

## 👨‍💼 管理者向けガイド

### 初回セットアップ

#### 1. ログインと基本設定

1. **初回ログイン**
   ```
   URL: https://your-quested-domain.com
   初期管理者ID: admin
   初期パスワード: (セットアップ時に設定)
   ```

2. **多要素認証（MFA）の設定**
   - ダッシュボード右上の「設定」→「セキュリティ」
   - 「MFA設定」をクリック
   - スマートフォンのGoogle AuthenticatorでQRコードをスキャン
   - バックアップコードを安全に保存

#### 2. 学校情報の登録

1. **学校の追加**
   - 「管理」→「学校管理」→「新規学校追加」
   - 必須項目を入力：
     - 学校名
     - 所在地
     - 電話番号・メールアドレス
     - 学校コード（一意の識別子）

2. **年度の設定**
   - 「学校管理」→該当学校を選択→「年度管理」
   - 年度情報を入力：
     - 年度名（例：2025年度）
     - 開始日・終了日
     - 現在年度フラグの設定

#### 3. ユーザー管理

**個別登録**:
1. 「管理」→「ユーザー管理」→「新規ユーザー」
2. 基本情報を入力：
   - ユーザー名（ログインID）
   - 氏名
   - メールアドレス
   - 役割（管理者・教師・生徒）
   - 所属学校

**一括登録**:
1. 「ユーザー管理」→「一括インポート」
2. CSVテンプレートをダウンロード
3. 必要な情報を入力してアップロード

**CSVフォーマット例**:
```csv
username,full_name,email,password,role,school_id
taro_yamada,山田太郎,taro@example.com,temp_password,student,1
hanako_sato,佐藤花子,hanako@example.com,temp_password,teacher,1
```

### 日常業務

#### 1. システム監視

**ダッシュボードの確認**:
- アクティブユーザー数
- システム稼働状況
- ストレージ使用量
- エラーログ件数

**定期メンテナンス**:
- 週1回：ユーザーアクティビティ確認
- 月1回：データベース最適化
- 四半期1回：セキュリティ監査

#### 2. ユーザーサポート

**パスワードリセット**:
1. 「ユーザー管理」→該当ユーザーを検索
2. 「パスワードリセット」をクリック
3. 仮パスワードを生成してユーザーに通知

**アカウント停止・再開**:
- 一時停止：「アカウント停止」
- 完全削除：「アカウント削除」（データは完全消去）

#### 3. レポート・分析

**利用統計レポート**:
- 「分析」→「利用統計」
- 期間を指定してレポート生成
- CSV/PDFでエクスポート可能

**セキュリティレポート**:
- 「分析」→「セキュリティ」
- ログイン失敗履歴
- 異常アクセスの検出

## 👩‍🏫 教師向けガイド

### 初期設定

#### 1. プロファイル設定

1. **基本情報の更新**
   - ダッシュボード→「プロファイル」
   - 専門科目、指導経験年数を入力
   - プロフィール写真のアップロード

2. **担当クラスの確認**
   - 「クラス」→「担当クラス一覧」
   - 管理者によって割り当てられたクラスを確認

#### 2. カリキュラム作成

**新規カリキュラムの作成**:
1. 「カリキュラム」→「新規作成」
2. 基本情報を入力：
   - カリキュラム名
   - 対象学年・科目
   - 実施期間
   - 学習目標

3. **単元の追加**:
   - 「単元追加」ボタンをクリック
   - 各単元の詳細を入力：
     - 単元名
     - 学習内容
     - 所要時間
     - 評価基準

**AIカリキュラム生成**:
1. 「AI支援」→「カリキュラム生成」
2. 条件を指定：
   - 科目・単元
   - 難易度レベル
   - 学習時間
3. AI生成結果を確認・調整

### 日常的な指導業務

#### 1. 生徒の進捗管理

**クラス全体の進捗確認**:
1. 「ダッシュボード」→「クラス概況」
2. 進捗状況をグラフで確認
3. 遅れている生徒を特定

**個別生徒の詳細確認**:
1. 「生徒」→「進捗詳細」
2. 学習履歴・活動記録を確認
3. コメントやフィードバックを記入

#### 2. 探究テーマの管理

**テーマ承認業務**:
1. 「探究テーマ」→「承認待ち」
2. 生徒が提出したテーマを確認
3. 承認・差し戻し・修正指導を実行

**メインテーマの作成**:
1. 「探究テーマ」→「メインテーマ管理」
2. クラス共通のテーマを作成
3. 生徒が選択できるテーマ候補を提供

#### 3. AI学習支援の活用

**AIチューター設定**:
1. 「AI設定」→「チューター設定」
2. 科目別のAIパーソナリティを調整
3. 難易度レベル・応答スタイルを設定

**AI評価支援**:
1. 生徒の提出物をAIで初期評価
2. AI評価結果を確認・調整
3. 最終評価とフィードバックを記録

#### 4. 評価・レポート作成

**ルーブリック評価**:
1. 「評価」→「ルーブリック作成」
2. 評価項目・基準を設定
3. 生徒の活動に対して評価を実行

**学習レポート生成**:
1. 「レポート」→「学習報告書」
2. 対象期間・生徒を選択
3. AI支援でレポートを自動生成
4. 内容を確認・調整して完成

### 高度な機能

#### 1. データ分析の活用

**学習分析ダッシュボード**:
- 学習時間の分析
- 理解度の推移
- 質問パターンの分析
- 興味・関心の変化

**クラス比較分析**:
- 複数クラス間の学習状況比較
- 指導方法の効果測定
- 改善点の特定

#### 2. 保護者との連携

**進捗共有機能**:
1. 「保護者連携」→「進捗共有設定」
2. 共有する項目を選択
3. 保護者向けレポートを自動生成

## 👦 生徒向けガイド

### アカウント設定

#### 1. 初回ログイン

1. **ログイン情報の確認**
   - 教師から配布されたユーザー名・パスワードを使用
   - 初回ログイン時にパスワード変更が必要

2. **プロファイル設定**
   - 「設定」→「プロファイル」
   - 自己紹介・興味分野を入力
   - アバター画像の設定

#### 2. 学習環境の準備

**興味・関心調査の実施**:
1. ダッシュボードの「調査回答」から実施
2. 学習スタイル・興味分野に関する質問に回答
3. AIがパーソナライズされた学習支援を提供

### 探究学習の進め方

#### 1. 探究テーマの選択・作成

**既存テーマから選択**:
1. 「探究」→「テーマ一覧」
2. 先生が用意したメインテーマを確認
3. 興味のあるテーマを選択

**オリジナルテーマの作成**:
1. 「探究」→「テーマ作成」
2. 以下の項目を入力：
   - テーマタイトル
   - 探究の動機
   - 探究方法
   - 期待される成果
3. 先生の承認を待つ

#### 2. 学習計画の立て方

**目標設定**:
1. 「目標」→「新規目標」
2. SMART原則に基づいた目標を設定：
   - Specific（具体的）
   - Measurable（測定可能）
   - Achievable（達成可能）
   - Relevant（関連性）
   - Time-bound（期限付き）

**TODO管理**:
1. 「TODO」→「新規追加」
2. 日々のタスクを細分化
3. 優先度・期限を設定
4. 完了したらチェックを入れる

#### 3. 学習活動の記録

**活動記録の作成**:
1. 「活動記録」→「新規記録」
2. 記録内容：
   - 日付・時間
   - 活動内容
   - 学んだこと・気づき
   - 写真・資料の添付
   - 振り返りコメント

**学習の振り返り**:
- 週末に1週間の学習を振り返り
- 上手くいったこと・改善点を記録
- 次週の計画を立て直し

#### 4. AI チューターとの対話

**基本的な使い方**:
1. ダッシュボードの「AIチューター」をクリック
2. 学習で困ったことを日本語で質問
3. AIから個別指導を受ける

**効果的な質問の仕方**:
- ❌ 「数学がわからない」
- ✅ 「二次関数のグラフの平行移動がわからない」
- ✅ 「なぜsin(x)の微分がcos(x)になるのか教えて」

### 学習成果の発表

#### 1. レポート作成

**探究レポートの構成**:
1. 表紙・目次
2. 探究の動機・目的
3. 探究方法
4. 結果・データ
5. 考察・結論

**AI支援機能の活用**:
- 文章構成のアドバイス

#### 2. プレゼンテーション

1. 「発表」→「新規プレゼン」
2. テンプレートを選択

4. 発表練習機能を活用

### 成績・評価の確認

#### 1. 学習進捗の確認

**個人ダッシュボード**:
- 学習時間の可視化
- 目標達成率

#### 2. ランキング・比較

## ❓ よくある質問 (FAQ)

### 一般的な質問

**Q: パスワードを忘れました**
A: ログイン画面の「パスワードを忘れた方」から、メールアドレスを入力してリセット用リンクを受け取ってください。

**Q: ブラウザは何を使えばいいですか？**
A: Chrome、Firefox、Safari、Edgeの最新版を推奨します。Internet Explorerは非対応です。

**Q: スマートフォンでも使用できますか？**
A: はい、レスポンシブデザインでスマートフォン・タブレットにも対応しています。

### 管理者向け

**Q: ユーザー数の上限はありますか？**
A: サーバーリソースに依存しますが、標準設定で1000ユーザーまで対応できます。

**Q: データのバックアップはどうすればいいですか？**
A: 管理画面からDBダンプの自動取得設定ができます。また、ファイルアップロードデータは別途バックアップが必要です。

**Q: セキュリティ監査機能はありますか？**
A: はい、すべてのユーザーアクションが記録され、異常なアクセスパターンを自動検出します。

### 教師向け

**Q: 一度に何人の生徒を担当できますか？**
A: システム上の制限はありませんが、効果的な指導のため40人程度を推奨しています。

**Q: 成績データをExcelでエクスポートできますか？**
A: はい、CSV形式でエクスポート可能で、Excelで開くことができます。

**Q: AIの回答内容が不適切な場合はどうしますか？**
A: 問題のある回答を報告機能で通知してください。AIの学習データから除外され、改善されます。

### 生徒向け

**Q: 活動記録は他の生徒に見られますか？**
A: 基本的には先生のみが閲覧可能です。クラス共有設定がある場合は他の生徒も閲覧できます。

**Q: AIチューターの回答は間違うことがありますか？**
A: AIは高精度ですが、完璧ではありません。重要な内容は必ず先生に確認してください。

**Q: アカウントを削除したい場合は？**
A: 先生または管理者にご相談ください。個人での削除はできません。

## 🔧 技術的なサポート

### システム要件

**推奨ブラウザ**:
- Google Chrome 100+
- Mozilla Firefox 100+
- Safari 15+
- Microsoft Edge 100+

**ネットワーク要件**:
- 安定したインターネット接続
- アップロード速度: 1Mbps以上
- ダウンロード速度: 5Mbps以上

### トラブルシューティング

**画面が正しく表示されない**:
1. ブラウザのキャッシュをクリア
2. 別のブラウザで試行
3. JavaScriptが有効か確認

**ファイルアップロードができない**:
1. ファイルサイズが16MB以下か確認
2. 対応形式（JPG, PNG, PDF, DOC等）か確認
3. ネットワーク接続を確認

**システムが重い・遅い**:
1. 他のタブ・アプリを閉じる
2. ブラウザを再起動
3. デバイスを再起動
